# Traffic Sign Recognition 

A deep learning-based system for automatic traffic sign classification using Convolutional Neural Networks (CNNs) with TensorFlow/Keras. The model is trained on a labeled dataset of road signs and achieves ~97% training accuracy.

# Features

CNN-based multi-class traffic sign classification

Data preprocessing & augmentation for robustness

Real-time prediction support using OpenCV

Modular training and inference scripts

# Model Overview

Framework: TensorFlow / Keras

Architecture: Custom CNN 

(Accuracy: ~97% training accuracy)
